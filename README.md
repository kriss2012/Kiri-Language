Kiri-Language

A Programming Language Built with Creativity, Simplicity, and Innovation

The goal is to build a language that makes programming easier to understand while providing a foundation for experimentation, learning, and future development.

Overview

Programming languages shape how developers express ideas and solve problems. Kiri-Language is an attempt to explore this process by building a dedicated language project from the ground up.

The project can serve as a foundation for experimenting with:

- Language syntax and grammar
- Lexical analysis and parsing
- Expressions and variables
- Data types and operators
- Control-flow statements
- Functions and reusable code
- Runtime execution and error handling

These are potential development areas, not a claim that every feature is already implemented.

Vision

The vision behind Kiri-Language is to develop a programming language with an understandable syntax, a well-organized implementation, and room for future expansion.

Design Principles

- Simplicity: Keep the language approachable and readable.
- Clarity: Make programs easier to understand and maintain.
- Modularity: Organize the implementation into maintainable components.
- Extensibility: Create room for additional language capabilities.
- Learning: Encourage experimentation with compiler and interpreter design.
